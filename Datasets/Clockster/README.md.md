
# Clockster – Attendance & Discipline Analysis

## 📌 Overview
This project analyzes employee attendance, discipline scores, and department-level behavior patterns using Clockster workforce data.

The goal is to identify:
- Top and bottom disciplined employees
- Department-level discipline
- Weekly and monthly attendance trends
- Tolerance index per department
- Actionable HR recommendations

---
## 🧰 Tools Used
- **Excel** (Power Query, Pivot Tables, Charts)
- **Power BI** (Visual dashboards)
- **SQL** (Data cleaning + preprocessing)

---
## 🗂 Data Sources
- Clockster exports: attendance logs, schedules, leave data, employee directory
- Formats: CSV, Excel
- Filtering rules: accepted/pending leave excluded

---
## 🔍 Methodology
1. Defined project goals (discipline scoring, temporal patterns)
2. Cleaned and normalized multi-sheet datasets
3. Built exposure-aware discipline score (0–100)
4. Computed tolerance index per department
5. Generated weekly & monthly trend analysis
6. Created dashboards (Power BI / Excel)
7. Summarized insights for stakeholders

---
## 📊 Key Findings
- **Pharmacy** is the most disciplined department
- **PBF** has lowest discipline score
- **Monday** = highest absences; **Thursday** = most late arrivals
- **March & May** see peak violations; **Nov–Dec** show improvement
- **Unassigned department** has highest tolerance index

---
## 📝 Recommendations
- Focus coaching on PBF + Unassigned
- Automate violation alerts and leave approval workflows
- Add Monday attendance reminders
- Add Thursday punctuality nudges
- Maintain reliability rules to reduce noise
